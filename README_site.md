# ПРО красоту

## Назначение
Локальный React-сайт премиального салона красоты «ПРО красоту» в Минске.

## Подтверждённые требования
- Город и адрес: Минск, улица Ежи Гедройца, 2.
- Аудитория: женщины, мужчины, семьи; премиум-сегмент.
- Обязательные блоки: услуги, мастера, цены, портфолио, отзывы, контакты, онлайн-запись.
- Стиль: luxury.
- Форма записи: нужна.
- Источники контента: Dikidi-профиль и страница услуг.
- Режим работы: локальная разработка, GitHub и production-публикация через Vercel.

## Технический план
- React + TypeScript.
- Локальная одностраничная презентационная страница.
- Адаптивная верстка для мобильных, планшетов и десктопов.
- Цены, услуги, мастера, отзывы и фотографии подключаются из проверенного контента Dikidi.

## Репозиторий и workflow

- GitHub: [SpiriT-L/pro-krasotu](https://github.com/SpiriT-L/pro-krasotu)
- Основная ветка: `main`.
- Каждая самостоятельная задача получает GitHub Issue и отдельную task-ветку.
- После локальных проверок и code review создаётся Pull Request в `main`.
- Merge, push и production deployment выполняются после согласования изменений.

## Ограничения и источники

Контент услуг, мастеров, цен, отзывов и фотографий получен из профиля Dikidi. Перед production-публикацией внешние данные необходимо повторно проверить. Для новых материалов фиксируются источник и дата последней проверки.

## Environment variables

Создайте `.env` на основе `.env.example` и укажите реальные значения локально или в Vercel Environment Variables:

```env
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=
PORT=4173
```

Файл `.env` не коммитится. Секреты используются только сервером и не должны попадать в клиентский код или публичный bundle.

## Локальный запуск
```bash
npm install
npm run dev
```

Проверка production-сборки:
```bash
npm run build
```

## Заявки в Telegram

Сервер отправляет заявки через Telegram Bot API. Для локальной проверки выполните `npm run build`, затем запустите `node server.mjs` и отправьте тестовую заявку через форму. Проверьте HTTP-ответ и получение сообщения в Telegram.

## Проверки перед Pull Request

```bash
npm ci
npm run build
git diff --check
```

Дополнительно проверьте мобильную версию, загрузку изображений, услуги, карточки мастеров, отзывы, модальные окна и форму заявки.

## Production deployment

Production URL: [pro-krasotu.vercel.app](https://pro-krasotu.vercel.app)

Перед публикацией проверьте environment variables, отсутствие localhost-ссылок, загрузку assets, работу API, мобильную версию и статус deployment `READY`. После публикации зафиксируйте URL, commit SHA и результат smoke-check.
